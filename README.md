# Calculateur de TVA Afrique

Outil simple pour convertir un montant HT ↔ TTC avec la TVA de plusieurs pays africains francophones.

## Fichiers
- `index.html` — page principale
- `style.css` — styles
- `script.js` — logique de calcul

## Déploiement sur GitHub Pages
1. Crée un nouveau dépôt public, par exemple `calculateur-tva`.
2. Ajoute les 3 fichiers (`index.html`, `style.css`, `script.js`) à la racine.
3. Va dans Settings → Pages.
4. Source : Deploy from a branch → branche `main` → dossier `/ (root)` → Save.
5. Le site est en ligne sur `https://TON-USER.github.io/calculateur-tva/` après 1–2 minutes.

## Étapes suivantes
- Acheter un nom de domaine (ex. calculateur-tva.com) et le lier à GitHub Pages.
- Ajouter robots.txt et sitemap.xml.
- S'inscrire à Google Search Console + Google Analytics.
- Créer des pages locales : calculateur-tva-rdc.html, calculateur-tva-cote-divoire.html…
- Dupliquer le concept pour d'autres outils (convertisseur FCFA, simulateur de prêt…).
